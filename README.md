# 東京・富士山深度自由行 2027（PWA 旅遊指南與完整手冊）

2027/01/29–02/03，6 天 5 夜。專屬接機＋河口湖包車、Day 6 押上站「京成 Access 特急」直達成田、公寓式客廳自炊和牛鍋物、東京經典地標景觀、動漫潮流旗艦、無提大包小包動線最佳化 ＆ 全面購物提示防護。

## 系統版本與特色亮點（v21 最新定案版）

1. **📲 一鍵安裝成手機桌面 App（PWA 獨立全螢幕＋離線運作）**：
   - 頂部右上角新增 **`📲 安裝 App`** 按鈕，點擊即可開啟專屬安裝引導彈窗（含 **Android Chrome 一鍵原生安裝觸發**、**iPhone Safari 加入主畫面步驟** 與 **一鍵複製網址傳給家人**）。
   - 安裝後在手機主畫面擁有專屬「東京富士山」圖示，點開即為**無瀏覽器網址列的獨立全螢幕 App**，並在搭機或地下鐵無網路時自動切換離線快取模式。
2. **🗣️ 旅行・購物・餐廳・交通 33 句「日語手指小卡 ＆ 全螢幕放大店員卡」**：
   - 頂部快捷鍵 `🗣️ 日語小卡` 與底部 `🗣️ 日語/SOS` 分頁內建 **5 大分類、33 張專為本次東京家庭行程量身打造的實用日語小卡**（`🍽️ 餐廳用餐 8 句`、`🛍️ 購物退稅 8 句`、`🏨 飯店交通 7 句`、`📸 拍照參拜 5 句`、`🚨 就醫求助 5 句`）。
   - 每張小卡皆附 **日文原文、羅馬拼音、中文說明**，支援點擊 `🔍 放大給店員看` 開啟全螢幕高對比大字卡，或點擊 `🔊 發音＋複製` 直接播放日語語音給店員／服務人員聽。
2. **當日行程動線專屬「即時天氣 API」**：
   - 自動串接免金鑰氣象 API（Open-Meteo JMA 氣象資料），一次同步 **6 大行程區域（桃園機場、成田機場、東京押上／晴空塔、富士山河口湖、東京池袋、原宿／東京鐵塔／東京站）**。
   - 切換 **Day 1 至 Day 6** 時，外層重點天氣列與展開後的「🌤️ D1–D6 當日行程即時天氣與穿搭建議」會自動切換為**該日實際造訪的行程站點與時段**（例如：D1 顯示桃園 ➔ 成田 ➔ 押上；D2 顯示富士山河口湖 ➔ 押上；D3 顯示東京池袋 ➔ 押上；D4 顯示原宿・東京鐵塔・東京站；D5 顯示淺草・晴空塔；D6 顯示押上 ➔ 成田 ➔ 桃園）。
   - 支援一鍵點擊 `🔄 即時天氣` 手動刷新，並自動快取至本機 `localStorage` 供離線查閱；進入出發前 16 天預報期內時，會自動對應各天行程日期的專屬預報。
2. **對齊最新「時間軸合理化、京成特急直達成田、流行伴手禮與季節活動」行程**：
   - **五大動線與時間軸合理化（Timeline Rationalization）**：
     - Day 1 成田出關預留 75 分鐘、週五傍晚專車進城預留 80 分鐘，19:10 抵達飯店。
     - Day 2 富士山週六回程預留 2.5 小時，18:30 返抵飯店，客廳壽喜燒時間充裕。
     - Day 3 陽光水族館調整為 14:30–15:45，早鳥晚餐 16:00–17:15 避開尖峰，採買衝刺線（17:20–19:15，含 Tartine 花束脆餅）更從容。
     - Day 4 明治神宮預留 85 分鐘、增上寺節分追儺祭典、丸之內香檳金點燈、東京站排隊伴手禮（N.Y.C. SAND / NEWYORK PERFECT CHEESE / Butter Butler）。
     - Day 5 淺草寺節分追儺會、晴空街道草莓祭、晴空塔 16:45 登塔看日落百萬夜景、東京芭娜娜海獺＆吉伊卡哇聯名款、Sugar Butter Sand Tree。
     - **Day 6 押上站「京成 Access 特急」一線直達成田機場**：13:20 回 KOKO HOTEL 領行李經無障礙電梯直通押上站地下月台，13:50 搭乘「京成 Access 特急（アクセス特急）」50 分鐘免換車直達成田機場（全家約 4,760 JPY），14:45 精準卡位起飛前 3 小時！
   - **21+ 項實戰「購物提示」**：免稅退稅條件、限定款搶購、折價券刷卡策略、易碎品防護、液體 STEBs 密封袋管制。
3. **日系簡潔可愛風（Light Mode Only）**：
   - 奶油米白底色（`#FFFDF8`）＋圓潤大卡片（`rounded-3xl`）＋珊瑚暖橘紅白（`#FF6B6B`），全站字體與卡片留白全面放大，閱讀極舒適。
4. **手機重點優先與摺疊詳細敘述**：
   - 手機版（`< 768px`）預設摺疊詳細敘述，外層只呈現時間、分類、中日文地名、交通/費用重點膠囊與司機卡快捷鈕；支援單張點擊與「全部展開/收合」。
5. **全螢幕黑體司機卡 ＆ Web Speech 語音發音**：
   - 無襯線大黑體展示目的地中日文與地址，內建 `🔊 播放語音（給司機聽）` 自動朗讀禮貌問候與地址，方便直接出示或播放給日本計程車/包車司機。
6. **即時雙向匯率 ＆ 多人分帳同步**：
   - 自動串接免金鑰匯率 API（`open.er-api.com` ＋ 備援），支援多人代墊公費結算與 Base64 旅伴一鍵同步碼。
7. **7 大分類詳細行李清單**：
   - 涵蓋行前預約 Timeline、重要證件、3C 充電、禦寒衣物、常備與兒童藥品、保濕護理與收納好物等 59 項詳細清單。

## 修改行程與文件同步

- 完整文字手冊位於 [ITINERARY.md](ITINERARY.md)，遵循台灣習慣用語、24 小時制標記當地時區與日圓/新台幣雙幣標示。
- 網頁資料集中於 `index.html` 頂部之 `ITINERARY_DATA`、`VOUCHERS_DATA`、`PACKING_DATA`。
- 修改後請將 `sw.js` 的 `CACHE_NAME` 版本號（如 `v17` ➔ `v18`）升版，手機瀏覽器才會自動更新快取。

## Netlify 拖曳部署

1. 開啟 <https://app.netlify.com/drop>。
2. 把整個 `Travel` 資料夾拖進頁面。
3. 取得網址後，用手機開啟。**請先在有網路時完整開啟一次**，讓 Tailwind、Lucide 與字型被快取，之後即可離線使用。
4. iPhone：Safari ➔ 分享 ➔ 加入主畫面；Android：Chrome ➔ ⋮ ➔ 安裝應用程式。

## 注意事項

- 訂位編號、訂單電話、保險專線為手動填寫欄位（存於本機 localStorage），請出發前自行輸入。
- 飯店與部分店家「官方網站」按鈕為 Google 搜尋頁（無法確認獨立官網時），營業時間與預約規則請以官方公告為準。
- 緊急電話請出發前至外交部領務局網站再核對一次。
- 旅伴同步：「複製分享碼」貼給旅伴，對方在「貼上同步」套用（會覆蓋對方的帳目與清單進度）。
